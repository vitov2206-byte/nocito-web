Politique de confidentialité

Comment Nocito™ traite vos données — et pourquoi la plupart ne quittent jamais votre téléphone.

Date d'entrée en vigueur : 1er juin 2025  ·  Dernière mise à jour : octobre 2026 (version v1.2)
🔒

La version courte

Nocito™ stocke toutes vos dépenses, reçus, images et fichiers audio localement sur votre appareil. Nous n'avons pas de serveur contenant vos données. Par défaut, le texte OCR assaini est envoyé à un service d'IA dans le cloud pour l'analyse des dépenses, et la dictée vocale utilise la transcription dans le cloud. Vous pouvez passer à un traitement et une transcription entièrement sur l'appareil en activant les modèles locaux dans les Réglages — cela nécessite un téléchargement unique dans l'application. L'import de PDF extrait le texte localement par défaut ; l'envoi du PDF complet dans le cloud est un réglage optionnel. En Croatie, la fonction Price Intelligence télécharge en outre sur votre téléphone les listes de prix publiques des enseignes et peut envoyer des noms de produits (après le filtre de confidentialité) à un service d'IA dans le cloud afin de relier les articles de vos reçus à ces listes ; cela n'a pas lieu lorsque le Traitement IA local est activé. L'application utilise Sentry pour signaler les plantages, ce qui inclut des données techniques comme votre adresse IP. Tout est détaillé dans cette politique.

1. Qui nous sommes

Nocito™ est une application mobile de suivi des dépenses personnelles développée et publiée par Nocito™ ("nous", "notre"). L'application est disponible sur Android via Google Play.

Vous pouvez nous contacter à : nocito.support@gmail.com

Données que nous ne collectons jamais

  • Nous ne collectons pas votre nom, adresse e-mail ni aucune information de compte (il n'y a pas de compte)
  • Nous ne collectons pas d'analyses ni de statistiques d'utilisation
  • Nous n'utilisons pas de SDK publicitaires ni de pixels de suivi
  • Nous ne synchronisons pas vos données de dépenses avec un quelconque serveur
  • Nous ne vendons vos données à personne

3. Pré-filtre de confidentialité — assainissement local des données

Pour les captures et importations de photos, Nocito™ exécute un processus d'assainissement local sur votre appareil avant d'envoyer tout texte à l'IA. Ce processus supprime :

  • Les noms personnels (motifs de prénom et nom de famille)
  • Les adresses physiques (rue, numéro, code postal, ville)
  • Les numéros d'identification nationaux (par exemple, numéros d'identification fiscale, numéros d'identification personnelle)
  • Les numéros de téléphone et adresses e-mail

Ce qui est conservé : montants, prix, dates, heures, noms de commerçants et d'entreprises, noms de produits, catégories et numéros de TVA des entreprises.

Ce processus s'exécute entièrement sur votre appareil avant tout appel réseau. Notez que le pré-filtre s'applique au texte OCR des captures et importations de photos. Il ne s'applique pas lorsque l'Extraction PDF dans le cloud est activée (le PDF complet est envoyé dans le cloud) ni à l'audio brut lors de la Transcription dans le cloud (l'audio est envoyé dans le cloud avant toute extraction de texte).

4. Dictée vocale

Nocito™ prend en charge deux modes de dictée vocale. La transcription dans le cloud est active par défaut lors d'une nouvelle installation. La transcription locale est disponible en option facultative et nécessite un téléchargement unique de modèle.

Transcription dans le cloud (par défaut)

Lors d'une nouvelle installation, appuyer sur le bouton Dicter enregistre l'audio et l'envoie à un service d'IA dans le cloud pour transcription. Le texte transcrit est ensuite traité par le pré-filtre de confidentialité (section 3) et envoyé à un service d'IA dans le cloud pour l'analyse de la dépense.

Transcription locale (facultative)

Vous pouvez passer à une transcription entièrement sur l'appareil dans les Paramètres en activant l'option Transcription locale et en téléchargeant l'un des deux modèles Whisper locaux disponibles. Le bouton de téléchargement est disponible directement sur l'écran Dictée ainsi que dans les Paramètres. Une fois configuré :

  • Appuyer pour enregistrer — utilise la transcription locale sur l'appareil. Aucun audio ne quitte votre téléphone.
  • Maintenir 1 seconde pour enregistrer — active Super Dictate (transcription dans le cloud) pour une plus grande précision si nécessaire.

Avec la transcription locale active, le texte transcrit est toujours envoyé par défaut à un service d'IA dans le cloud pour l'analyse de la dépense — sauf si vous activez également le traitement IA local (voir section 4c).

Dictée 100 % privée : pour vous assurer qu'aucune donnée vocale ou textuelle ne quitte votre appareil, activez à la fois la Transcription locale et le traitement IA local dans les Paramètres. Les deux nécessitent un téléchargement unique de modèle. Ceci est recommandé pour les utilisateurs pour qui la confidentialité est plus importante que la précision maximale et qui disposent d'un appareil suffisamment rapide.

4b. Importation de PDF

Nocito™ traite les reçus PDF localement par défaut. L'application utilise l'OCR sur l'appareil (ML Kit) pour extraire le texte du PDF, applique le pré-filtre de confidentialité et n'envoie que le texte assaini à un service d'IA dans le cloud pour l'analyse de la dépense.

Une option facultative d'Extraction PDF dans le cloud est disponible dans les Paramètres. Lorsqu'elle est activée, le document PDF complet est envoyé directement à un service d'IA dans le cloud pour une analyse plus précise. Cette option est facultative et désactivée par défaut.

Pour que le traitement PDF reste 100 % sur l'appareil, laissez l'Extraction PDF dans le cloud désactivée et activez le traitement IA local dans les Paramètres (nécessite un téléchargement de modèle).

Lorsque l'Extraction PDF dans le cloud est activée : le document PDF complet est envoyé à un service externe sans pré-filtrage local. Nous recommandons de laisser cette option désactivée sauf si vous avez besoin d'une plus grande précision sur des PDF complexes, et d'éviter de l'utiliser avec des PDF contenant des informations personnelles sensibles.

Nocito™ vous donne un contrôle direct sur le traitement qui se fait localement et celui qui utilise des services dans le cloud. Ces paramètres sont disponibles sur l'écran Paramètres de l'application :

Désactivez et téléchargez un modèle d'IA local pour traiter toute l'extraction des dépenses entièrement sur l'appareil. Téléchargement disponible dans les Paramètres.

Les modifications de ces paramètres prennent effet immédiatement. Vos dépenses existantes ne sont pas affectées.

4d. Price Intelligence (Croatie)

Price Intelligence n'est actuellement disponible que pour le marché croate. Elle compare les articles de vos reçus aux listes de prix que les enseignes croates sont légalement tenues de publier. Elle ne s'active qu'après que vous avez choisi des magasins dans l'application.

  • Listes de prix : votre téléphone télécharge les listes de prix publiques directement depuis les sites web des enseignes dont vous avez choisi les magasins. Ces sites voient une requête internet ordinaire de votre appareil (par exemple son adresse IP). Nous ne recevons pas ces requêtes et vos reçus ne sont jamais envoyés aux enseignes.
  • Vos magasins : vous choisissez les magasins en saisissant une ville ou un code postal. Ce choix reste sur votre appareil. Nocito n'utilise ni le GPS ni votre position.
  • Mise en correspondance : la plupart des articles des reçus sont associés sur votre téléphone aux produits des listes de prix. Pour les noms abrégés ou peu clairs, le nom du produit (après le filtre de confidentialité et, dans certains cas, le prix) est envoyé à un service d'IA dans le cloud. Un quota mensuel de liaison d'articles s'applique.
  • Traitement IA local : lorsque le Traitement IA local est activé, Nocito n'envoie aucun nom de produit à un service d'IA dans le cloud pour Price Intelligence.
  • Scanner de codes-barres et alertes de prix : les codes-barres sont lus sur votre appareil et recherchés dans les listes de prix enregistrées sur le téléphone ; l'image de la caméra n'est envoyée nulle part. Les alertes de prix sont vérifiées sur votre téléphone et affichées sous forme de notifications locales.
  • Dictée de la liste de courses : fonctionne comme la dictée (section 4) : l'audio est transcrit dans le cloud sauf si vous utilisez la transcription locale, et le texte est traité par un service d'IA dans le cloud sauf si le Traitement IA local est activé.

5. Super Snap (futur) et Super Dictate (Pro)

Les futures versions Pro de Nocito™ incluront Super Snap — une fonctionnalité premium qui envoie des images complètes de reçus directement à un service de vision par IA pour une extraction de plus grande précision, en contournant le flux OCR et de pré-filtre de confidentialité standard.

Super Dictate, qui envoie l'audio à un service de reconnaissance vocale dans le cloud (OpenAI Whisper) pour une transcription plus précise, est disponible dans la version actuelle : quelques sessions par mois avec l'offre gratuite, davantage avec Pro.

Lors de l'utilisation de Super Snap ou Super Dictate : votre image ou enregistrement audio complet est transmis à un service d'IA externe. Une confirmation vous sera toujours demandée avant toute transmission de ce type. Évitez d'utiliser ces fonctionnalités avec des documents contenant des informations personnelles sensibles.

7. Stockage des images et de l'audio

Les images de reçus et les enregistrements audio sont stockés dans le répertoire privé de l'application de votre appareil — un emplacement auquel les autres applications ne peuvent pas accéder. Ils ne sont téléchargés vers aucun service dans le cloud.

Vous pouvez contrôler ce comportement :

  • Enregistrer les images originales — ACTIVÉ par défaut. Peut être désactivé dans les Paramètres ou lors de l'intégration.
  • Enregistrer l'audio original — ACTIVÉ par défaut. Peut être désactivé dans les Paramètres ou lors de l'intégration.

Sauvegarde locale : Nocito™ propose une fonction de sauvegarde ZIP locale qui exporte un fichier JSON contenant tous vos enregistrements de dépenses ainsi que toutes les images originales, PDF et enregistrements audio attachés à ces dépenses. Vous pouvez restaurer cette sauvegarde à tout moment. Vous êtes responsable de la conservation de vos propres copies de sauvegarde — Nocito™ ne conserve aucune copie de vos données côté serveur. Si vous désinstallez l'application sans sauvegarde, toutes les données sont définitivement supprimées.

8. Stockage cloud futur

Nocito™ pourrait introduire des fonctionnalités de synchronisation cloud facultatives dans les futures versions. Toute fonctionnalité de ce type stockerait vos données sur des serveurs externes et serait entièrement facultative. Les utilisateurs gratuits et Pro locaux ne seraient pas affectés. Une divulgation et un consentement distincts seraient présentés avant tout téléchargement de données vers des serveurs externes.

Aucune synchronisation cloud n'est disponible dans la version actuelle.

9. Base légale du traitement (RGPD)

Pour les utilisateurs de l'Union européenne et de l'Espace économique européen, nous traitons les données selon les bases légales suivantes :

  • Exécution du contrat — traitement de vos données de dépenses pour fournir la fonctionnalité principale que vous avez demandée
  • Intérêts légitimes — envoi de texte OCR assaini à des services d'IA dans le cloud pour fournir une catégorisation précise des dépenses
  • Intérêt légitime — envoi de noms de produits (après le filtre de confidentialité) à des services d'IA dans le cloud pour relier les articles des reçus aux listes de prix (Price Intelligence, uniquement après le choix de magasins et uniquement si le Traitement IA local est désactivé)
  • Intérêt légitime — signalement des plantages via Sentry pour maintenir la stabilité de l'application
  • Consentement — envoi d'audio à un service de transcription dans le cloud (uniquement lorsque la Transcription dans le cloud est activée dans les Paramètres)
  • Consentement — envoi de documents PDF complets à un service d'IA dans le cloud (uniquement lorsque l'Extraction PDF dans le cloud est activée dans les Paramètres)

Comme l'application fonctionne principalement sur l'appareil sans système de compte, les données personnelles que nous traitons sont minimes. Le responsable principal de vos données personnelles est vous-même — elles vivent sur votre appareil.

10. Vos droits

Conformément au RGPD et à d'autres lois applicables, vous avez le droit de :

  • Accès — exportez vos dépenses au format CSV depuis l'application (fonctionnalité Pro)
  • Sauvegarde et restauration — exportez toutes vos données sous forme de sauvegarde JSON et restaurez-les sur n'importe quel appareil (disponible pour tous les utilisateurs)
  • Suppression — supprimez des dépenses individuelles ou toutes les données depuis l'application, ou désinstallez l'application pour tout supprimer
  • Portabilité — exportez vos données au format CSV ou JSON à tout moment
  • Rectification — modifiez toute dépense directement dans l'application

Comme nous ne conservons pas de copie de vos données côté serveur, la plupart des droits peuvent être exercés directement dans l'application. Pour toute question : nocito.support@gmail.com

10b. Rapports de plantage

Nocito™ utilise Sentry (sentry.io, région de données UE) pour signaler les plantages. Lorsque l'application plante ou rencontre une erreur inattendue, Sentry reçoit un rapport technique contenant :

  • Stack trace (description technique de l'endroit du code où l'erreur s'est produite)
  • Modèle et fabricant de l'appareil
  • Version d'Android
  • Version de l'application
  • Votre adresse IP, que Sentry reçoit avec chaque requête
  • Une courte trace des événements techniques récents précédant l'erreur

Les rapports ne sont pas destinés à contenir vos données de dépenses, images de reçus ou enregistrements audio, et nous ne les utilisons que pour trouver et corriger des bugs. Comme ils comprennent des identifiants techniques tels qu'une adresse IP, ils constituent des données personnelles au sens du RGPD. Le signalement des plantages est actif dans l'application publiée et ne peut actuellement pas être désactivé dans les Réglages. Politique de confidentialité de Sentry : sentry.io/privacy

11. Confidentialité des enfants

Nocito™ ne s'adresse pas aux enfants de moins de 13 ans (ou de moins de 16 ans dans l'UE). Nous ne collectons pas sciemment d'informations personnelles auprès d'enfants. Si vous pensez qu'un enfant nous a fourni des informations personnelles, veuillez nous contacter à nocito.support@gmail.com.

12. Modifications de cette politique

Nous pouvons mettre à jour cette Politique de confidentialité à mesure que l'application évolue — en particulier lors de l'introduction de nouvelles fonctionnalités impliquant la transmission de données (comme Super Snap dans une future version, ou des modifications de la gestion des PDF et de la Dictée). Lorsque nous apporterons des modifications importantes, nous vous en informerons via la fenêtre contextuelle "Nouveautés" de l'application et mettrons à jour la date d'entrée en vigueur ci-dessus.

L'utilisation continue de Nocito™ après les modifications constitue une acceptation de la politique mise à jour.
